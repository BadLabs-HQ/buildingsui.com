# Building Sui ($BUILD)

Community site for the $BUILD memecoin. Static React app built for Walrus Sites.

## Develop

```
npm install
npm run dev
```

## Launch day

Edit `src/config.ts`:

1. `TOKEN.coinType`: the full coin type. This switches on live stats, chart, contract and buy buttons.
2. `TOKEN.launchAt`: ISO date for the countdown (before launch).
3. `CURATOR_ADDRESS`: wallet that receives meme submissions for review.
4. `SOCIALS`: X, Telegram, Discord links.

## Meme wall

1. Submissions are stored on Walrus from the user's wallet and transferred to `CURATOR_ADDRESS`.
2. To approve one, add it to `src/data/memes.ts` with `walrusMeme('<blob id>')` and redeploy.
3. Starter memes are generated by `node scripts/make-starter-memes.mjs`.

## Deploy to Walrus Sites

```
npm run build
site-builder deploy dist --epochs max
```

After the first deploy, copy `dist/ws-resources.json` (now holding the site object ID) back to `public/ws-resources.json` and commit it, so later deploys update the same site.
