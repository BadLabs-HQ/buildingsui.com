# Building Sui ($BUILD)

Community site for the $BUILD memecoin on Sui. Static React app, live at https://www.buildingsui.xyz.

## Develop

```
npm install
npm run dev
```

## Deploy

Every push to `main` deploys to production on Vercel.

## Market data

Price, stats, chart, wallet balance and the buy button all read from `MARKET` in `src/config.ts`.

Until $BUILD launches, $MANIFEST stands in as placeholder data, and each data section shows a "Placeholder" badge.

## Launch day

Edit `src/config.ts`:

1. `MARKET.coinType` and `MARKET.ticker`: $BUILD's full coin type and ticker.
2. `MARKET.placeholder`: set to `false` to remove the placeholder badges.
3. `TOKEN.launchAt`: ISO date for the countdown (before launch).
4. `CURATOR_ADDRESS`: wallet that receives meme submissions for review.
5. `SOCIALS`: X, Telegram, Discord links.

## Meme wall

1. Submissions are stored on Walrus from the user's wallet and transferred to `CURATOR_ADDRESS`.
2. To approve one, add it to `src/data/memes.ts` with `walrusMeme('<blob id>')` and push.
3. Starter memes are generated by `node scripts/make-starter-memes.mjs`.
